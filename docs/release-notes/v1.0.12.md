# Scanly v1.0.12.1

## 🛠️ Fixes

- Fixed a crash when opening QR Scan in minified release builds after granting camera permission.
- Fixed a crash when opening Create QR directly.
- Hardened ML Kit barcode and CameraX startup and cleanup for release APKs.
- Prevented Create QR from briefly initializing the Scan camera flow.

## 📦 Upgrade notes

This is a stability release on top of Scanly v1.0.11. Existing documents, libraries, and `.scanly` backups remain supported.
