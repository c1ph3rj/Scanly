## ✨ What's new

- 🗄️ **Library backup and restore** — Create portable `.scanly` backups with progress, cancellation, validation, and Replace or Merge restore.
- 📄 **Advanced PDF export** — Add passwords, page numbers, orientation, print sizes, and margin controls.
- 📁 **Flexible save location** — Save directly to `Downloads/Scanly` or a folder you choose.
- 📷 **Improved scanning** — New onboarding, clearer capture guidance, and refined portrait and landscape layouts.
- 🎨 **10 enhancement filters** — Added Auto and Shadow Reduction with improved image processing.
- 🔍 **Better page review** — Swipe between pages with improved zoom, reset, retake, and delete controls.
- 🏷️ **Smarter organization** — Suggested duplicate-safe names and clearer library filters.
- 🔄 **Update channels** — GitHub updates for direct installations and Google Play updates for Play Store installations.

## 🛠️ Fixes

- ✅ Retakes now return to the correct editor or preview.
- 🖼️ Renaming a document no longer replaces its thumbnail.
- 📐 Fixed duplicate top spacing and improved export layouts.

> 🔐 Backups are compressed but not encrypted. Store sensitive backup files securely.
