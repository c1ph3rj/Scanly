# Scanly v1.0.14

## Clearer empty states and faster folder organization

Scanly v1.0.14 makes first-use screens more useful and easier to understand while keeping the offline-first workflow unchanged.

- Shared illustrated empty states across Home, Library, folders, documents, PDF tools, and detector benchmarking
- Clearer empty-state wording and prominent next actions
- Consistent illustration sizing and spacing, including a larger detector benchmark illustration
- Multi-select existing documents when adding documents to a folder
- Existing document, library, and `.scanly` backup compatibility is preserved
