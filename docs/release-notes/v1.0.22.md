# Scanly v1.0.22

- **Welcome switches languages offline.** Google Play installs now include all 25 app languages. Choose one and the welcome screen and introduction switch right away.
- **Apply language changes in Settings.** Select a language or **System default**, then tap **Apply** to save it and switch. Back out to keep your current language.
- **Clearer full-screen previews.** Image and PDF preview controls stay clear of display cutouts in landscape.
