# Scanly v1.0.17

## Cleaner pages, a calmer library, and tools that walk you through

Scanly v1.0.17 rebuilds page filters, redesigns the Library and Home, and turns every tool into a short, guided flow.

- Filters even out paper lighting without flattening photos or colour ink; eight presets and a new Intensity slider
- The Library opens on search, a folder shelf, and documents grouped by day; Home gains the same search bar
- PDF tools now go choose a file → options → done, with a real preview of the result and a file name you can edit
- Watermarks read upright on rotated scans, always fit the page, tile in even rows, and come in four colours with presets and an optional date
- Password can stop others editing or copying text; Merge lets you order files and name the result first
- The PDF reader has a pages grid for jumping around long files
- QR results are shaped by type: links show the full domain, UPI shows the payee, Wi-Fi joins in one tap, contacts save
- Create Link, Text, Wi-Fi, UPI and Contact codes with a caption and dark ink colours; history stays on your phone
- A clearer light theme and a fixed navigation bar
- Library backup and restore have been removed
