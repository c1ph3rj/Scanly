# Scanly v1.0.21

## Split PDFs and documents, and a friendlier Tools hub

Cut PDFs and scanned documents into parts, reach every PDF tool straight from a document, and send feedback from inside the app.

- Split PDF: cut a PDF by custom ranges, every N pages, or by extracting the pages you pick; the original is never changed
- Split a scanned document into new documents, with page text and signatures copied; keep the original or send it to Recently deleted
- Compress, Merge, Split, Password, Watermark and Save as images now open from a document's ⋮ menu
- Every Tools tile shows a small picture of what it does
- A warmer Paper Atelier first-run introduction with Pip
- Send feedback from Settings, with up to 5 images attached
- Rate Scanly now opens Google Play reliably, and the feedback image picker only offers the slots you have left
